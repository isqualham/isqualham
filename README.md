### 💻 Projetos em destaque

#### 🐳 Flags API — Docker Challenge

API REST de *feature flags* desenvolvida para demonstrar práticas de desenvolvimento de APIs, conteinerização, automação e segurança.

- **Tecnologias:** Node.js, TypeScript, PostgreSQL, Docker, Docker Compose e Docker Scout.
- **Destaques técnicos:**
  - Multi-stage build utilizando Node.js 22 Alpine, com imagem final de aproximadamente 63 MB.
  - Separação dos ambientes de desenvolvimento e produção com Docker Compose.
  - Configuração de `develop.watch` para atualização durante o desenvolvimento.
  - Healthchecks e execução de migrações do banco de dados.
  - Execução com usuário não privilegiado e geração de SBOM e proveniência.
  - Auditoria de vulnerabilidades com Docker Scout.
