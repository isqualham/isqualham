#### 🐳 Flags API — Docker Challenge

API REST de feature flags desenvolvida para demonstrar práticas de desenvolvimento, conteinerização e segurança.

**Tecnologias:** Node.js, TypeScript, PostgreSQL, Docker, Docker Compose e Docker Scout.

**Destaques técnicos:**
- Multi-stage builds e otimização de imagens Docker.
- Separação de ambientes de desenvolvimento e produção.
- Healthchecks e migrações de banco de dados.
- Execução com usuário não privilegiado.
- Geração de SBOM e proveniência.
- Auditoria de vulnerabilidades com Docker Scout.

**Repositório:** [fc4-desafio-docker-node-api](https://github.com/isqualham/fc4-desafio-docker-node-api)
