### 💻 Projetos em Destaque

#### 🐳 [Flags API — Docker Challenge](https://github.com)
API REST de feature flags desenvolvida para demonstrar práticas avançadas de DevOps, conteinerização e segurança.

* **Tecnologias:** Node.js, TypeScript, PostgreSQL, Docker, Docker Compose, Docker Scout.
* **Destaques Técnicos:**
  * Configuração de **Multi-stage build** otimizada com Node 22 Alpine (imagem final de apenas 63MB).
  * Separação de ambientes (Dev/Prod) com Docker Compose e uso de `develop.watch` para live-reload.
  * Pipeline de automação com verificação de integridade (*healthchecks*) e execução prévia de migrações do banco de dados.
  * Segurança reforçada: execução com usuário não-privilegiado, geração de **SBOM/proveniência** e auditoria de vulnerabilidades zerada via Docker Scout.
